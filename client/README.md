# Joineazy frontend

This directory contains the React + Vite client for the Joineazy student and professor workspaces. Install dependencies with `npm install`, configure the optional `VITE_API_URL` environment variable if the API is not at `http://localhost:5001/api`, and run `npm run dev`.

For full setup instructions, frontend features, API route contracts, and known backend integration gaps, see the [project README](../README.md).
